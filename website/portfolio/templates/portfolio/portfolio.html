How I ship with AI

I built a pipeline of AI agents that takes a GitHub issue from plan to production. Each change passes six stages, and any stage can stop it.

{% if pipeline.working_on %} Working on #{{ pipeline.working_on.number }} {% else %} Factory idle {% endif %} {# The animation is always a replay of a finished change: GitHub does not expose live stages. #} {% if pipeline.last_shipped %} Replaying the last shipped change: #{{ pipeline.last_shipped.number }} {% else %} Replaying how a change moves through the stages {% endif %}
  1. 01PlanA planner agent turns the issue into small tasks.
  2. 02BuildAn engineer agent implements one task at a time.
  3. 03ReviewA different model reviews the diff against the plan.
  4. 04VerifyA verifier checks every finding against the code.
  5. 05CIMigration check, deploy check and the full test suite.
  6. 06DeployI merge it myself. A failed health check rolls back.

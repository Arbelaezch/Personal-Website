Nginx
/etc/nginx/sites-available/christiandonovan.ca 
-> Main Nginx configuration file that defines how requests are handled 
-> Linked to sites-enabled via: /etc/nginx/sites-enabled/christiandonovan.ca

sudo nginx -t 
sudo systemctl reload nginx

sudo tail -f /var/log/nginx/error.log



Gunicorn
/etc/systemd/system/gunicorn.service # Production service
-> Systemd service files that control how Gunicorn runs 
-> Define user, working directory, and socket locations

# Create/edit the service file 
sudo nano /etc/systemd/system/gunicorn.service 

# After pasting and saving the above content: 
sudo systemctl daemon-reload 
sudo systemctl restart gunicorn 
sudo systemctl status gunicorn



Firewall (UFW) - intended open ports on meditations
-> 22/tcp    OpenSSH   key login from anywhere; password login only from 192.168.1.0/24
-> 80,443    Nginx Full  public web (christiandonovan.ca)
-> 8096/tcp  Emby media server
-> Samba     192.168.1.0/24 only (EmbyMovies share, login as carb)
Everything else is closed. MySQL (3306) listens on 127.0.0.1 only.
fail2ban watches sshd and nginx (jail config: /etc/fail2ban/jail.d/local.conf).
SSH hardening: /etc/ssh/sshd_config.d/10-hardening.conf


Deploys (GitHub Actions: .github/workflows/main.yml)
-> Push to main -> tests -> SSH to christiandonovan.ca as the deploy user -> fast-forward pull,
   pip install, migrate, collectstatic, restart gunicorn.
-> Health check afterwards: / and /api/v1/recipes/ must answer through nginx + gunicorn + DB.
   If anything fails the code is rolled back to the previous commit (migrations are NOT rolled
   back, so keep them backwards compatible) and the job fails (GitHub emails the failure).
-> The server pulls from GitHub with ~/.ssh/github_deploy_key (see ~/.ssh/config for carb).
-> The deploy user may only run: sudo systemctl restart gunicorn. The deploy installs no
   system packages. Needed once on a new server:
   sudo apt-get install -y python3-venv python3-dev pkg-config default-libmysqlclient-dev build-essential
-> Server Python venv: /var/www/portfolio/env (python3.12). To recreate:
   python3 -m venv env && env/bin/pip install -r requirements.txt
